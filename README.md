> **RFYT (RealFakeYT)** adalah aplikasi Android klien YouTube unofficial yang ringan, bebas iklan, dan open-source. Dibangun dengan Kotlin native, dirancang agar mudah dimodifikasi, dan mendukung scraping langsung tanpa API key berbayar.
>
> 👑 **BY KIYARA.**

---

## 🌟 Fitur Utama

- 🚫 **Bebas Iklan (Ad-Free Streaming)**: Menonton video YouTube tanpa interupsi iklan yang mengganggu.
- ⧉ **Picture-in-Picture (PiP Mode)**: Tonton video di jendela mengambang mini sambil membuka aplikasi lain (chatting, medsos, dsb.).
- 🔍 **YouTube Scraper Live**: Mencari video YouTube secara instan langsung dari `youtube.com/results` dengan fallback instance Invidious.
- ⬇ **Pintasan Unduh MP4**: Tombol cepat untuk mengunduh video favorit langsung ke memori HP.
- 🎨 **Desain Neon Glitch YouTube Dark**: Antarmuka Cyberpunk Dark Mode dengan aksen YouTube Red dan Cyan Glow.
- ☁ **Otomatis Build APK di GitHub Actions**: APK otomatis ter-compile di cloud tanpa perlu Android Studio di PC lokal.
